Learn by doing

Your first 7aba programs

Download the interpreter, write a small .7ba file, and run it. No compiler setup is needed.

1. Get set up

  1. Download the Windows interpreter.
  2. Save 7aba.exe in the folder where you keep your program.
  3. Open PowerShell in that folder.

To run a program named hello.7ba:

.\7aba.exe run .\hello.7ba

Keep PowerShell open to see output and runtime errors. Users only need the executable and their .7ba file.

2. Hello, world

Create hello.7ba in a text editor:

display "Hello, world!"

Save the file, then run the command from the first lesson. display writes values to the terminal.

3. Values and variables

Assign values with =. Variables can hold numbers, text, booleans, null, or managed collections.

name = "Ada"
visits = 3
ready = true

display "Welcome, " name
next_visit = visits + 1
display next_visit

Optional scalar annotations check that a variable keeps the declared value type:

tries: Int = 3
message: String = "start"
tries = tries + 1
Supported annotations are Int, Float, Bool, String, and Null. They are optional.

4. Conditions and loops

when chooses a branch. An otherwise block runs when its condition is false.

score = 82

when score >= 80 {
    display "pass"
}
otherwise {
    display "try again"
}

Use while to repeat while a condition is true, or repeat for a fixed count:

step = 0
while step < 3 {
    display step
    step = step + 1
}

5. Actions

An action is a named block that can accept arguments and be called more than once.

action greet(name) {
    display "Hello, " name
}

greet("Mina")
greet("Omar")

Use empty inside an action to return early.

6. Lists and their display

Create a list and add values with push. Lists use zero-based indexes.

list scores
push scores 12
push scores 24
push scores 36

display scores[0]
len scores size
display scores

When displayed, a list is shown as an indexed table. This makes the contents easier to inspect while your program runs.

TABLE scores (length=3)
┌───────┬───────┐
│ INDEX │ VALUE │
├───────┼───────┤
│ [0]   │ 12    │
│ [1]   │ 24    │
│ [2]   │ 36    │
└───────┴───────┘

7. Other collections

Piles, matrices, and queues have structure-specific commands and readable displays.

pile history
push history 10
push history 20
display history

matrix grid 2 3
matrix_set grid 0 1 7
display grid

queue jobs
enqueue jobs 31
enqueue jobs 42
display jobs
  • Piles mark their top item.
  • Matrices show row and column indexes.
  • Queues show FIFO order and mark the front and back.

Maps and sets support literals, lookup, and membership tests. Their current display uses the regular value format.

8. Strings and math

Built-in functions can trim, search, and transform strings, or perform common math operations.

text = trim("  hello  ")
changed = replace(text, "hello", "7aba")
found = contains(changed, "7aba")
where = index_of(changed, "7")
copies = repeat("ha", 2)
distance = sqrt(81)

display changed
display found

String positions and searches operate on bytes; ASCII case helpers do not implement Unicode case conversion. Math trigonometry uses radians.

9. Read and write text files

File commands use paths relative to the folder where you started the interpreter.

message = "Hello from 7aba"
file_write "notes.txt" message overwrite
file_read "notes.txt" contents
display contents

Text file reads are bounded. Programs can also create a .state sidecar file to persist supported global values between runs.
