7aba-Lang for Windows (32-bit)

Files
-----
7aba.exe   The standalone 7aba interpreter.
hello.7ba  A small example program.

Run the example
---------------
Open PowerShell in this folder and run:

  .\7aba.exe run .\hello.7ba

Run another program
-------------------
Put your .7ba file beside 7aba.exe, then run:

  .\7aba.exe run .\your-file.7ba

No C compiler or separate runtime installation is required.

SHA-256 checksums for the downloads are available in SHA256SUMS.txt beside
the archive on the 7aba-Lang download page.
