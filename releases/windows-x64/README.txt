7aba-Lang for Windows (64-bit)

Files
-----
7aba.exe   The standalone 64-bit 7aba interpreter.
hello.7ba  A small example program.

Run the example
---------------
Open PowerShell in this folder and run:

  .\7aba.exe run .\hello.7ba

Run another program
-------------------
Put your .7ba file beside 7aba.exe, then run:

  .\7aba.exe run .\your-file.7ba

No C compiler or separate runtime installation is required.
